=== STAGE 6: THE BLACK GATE ===

Aragorn's forces march to the doors of Mordor. But the Gate will test them.
Sauron's Eye watches without ceasing. Any guard who falls silent draws
the Enemy's full attention. Any scout unprepared to answer commands
weakens the wall.

Your container army at Minas Tirith now needs two defenses:
A cold corpse does not fight. Through a liveness probe, Kubernetes
checks "is this Pod alive?" — if not, restarts it automatically.
A recruit not yet ready does not charge into battle without equipment.
Readiness probes ask "can you take traffic?" — if not, the Pod is
removed from service endpoints.

And when Black Gate cracks and more wargs swarm Western Plains,
you need HPA's auto-reinforcements: when CPU fills, reinforcements arrive.

Now Aragorn must reveal his true strategy. He configures:" 
- Liveness probes — keep the firewall of Gondor living.
- Readiness probes — stop pods from sending traffic errors.

Create a Deployment with liveness and readiness Probes. Set resource
requests and limits. Add HPA to scale when mocked loads occur.

OBJECTIVE:

To fortify against corruption and death, a Pod must be configured with
resource consumption boundaries and a check for vital signs and response.

REQUIRED SETUP:

Namespace:    'black-gate'       (create this now)

Defensive Deployment (named 'defense-line'):
    Replicas: 2 (initial line)
    Image: nginx
    CPU limit: 500m / Request: 100m
    Memory limit: 128Mi / Request: 32Mi
    
Probes for Deployment:
  liveness: httpGet path /health  port 8080 period 5s
  readiness: httpGet path /ready port 8080 period 3s

And add HPA to scale when mocked loads occur:
- Name: line-reinforcements (or any valid name)
- Target: Deployment 'defense-line'
- Min: 2
- Max: 5
- CPU Thresh: 60%

TESTING IT:
Create the Deployment with both liveness and readiness probes.
Use the HTTP /health and /ready endpoints on port 8080.
Verify it works by checking the Deployment spec shows both probes.

Kill one Pod to simulate a sentry falling — watch the Deployment recover.
Scale to mock pressure and watch HPA spawn reinforcements.

When the Deployment holds steady and HPA stands ready, run 'check_black_gate' to seal the gap.
